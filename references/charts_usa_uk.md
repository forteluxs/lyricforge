## Cross-Market Patterns (USA/UK)

### Structural trends:
- Standard pop: **V1 → Pre-C → C → V2 → Pre-C → C → Bridge → Final C**
- Country: **V1 → C → V2 → C → Bridge → Final C (extended)**
- Hip-hop: **Verse → Hook → Verse → Hook** (short hook, 4-8 bars)
- Soul: **V → C → V → C → Outro (vamp)**

### Lyrical devices dominating 2026:
- **Medical metaphors** (Olivia Rodrigo): poison, toxins, cure
- **Geography as emotion** (Ella Langley): Texas/Tennessee = heartbreak
- **Vampire/dark imagery** (Tame Impala): isolation, nightlife
- **Self-assurance** (Olivia Dean): first-person confidence, humor
- **Direct address** (Drake): calling out real people by name

### Rhyme schemes:
- Country: ABAB in verse, AABB or AAAA in chorus
- Pop-rock: Often slant rhyme (Olivia Rodrigo)
- Hip-hop: Internal rhyme, multisyllabic rhyme chains
- Soul: End rhyme + call-response patterns
